# Nauxica Logo Assets

Generated from the Canva SVG master uploaded in this conversation.

Recommended usage:
- Navbar: assets/logo/nauxica-wordmark.svg
- Hero / PDF / presentation: assets/logo/nauxica-logo-primary.svg
- Footer on dark background: assets/logo/nauxica-logo-primary-white.svg
- Icon / favicon / app icon: assets/logo/nauxica-logo-mark.svg
- Browser favicon: assets/logo/favicon.ico
- Apple touch icon: assets/logo/apple-touch-icon.png

Naming notes:
- `white` keeps the terracotta X and converts dark elements to linen.
- `all-white` converts all visible elements to linen for dark backgrounds.
- PNG files are rendered from the SVG versions.
