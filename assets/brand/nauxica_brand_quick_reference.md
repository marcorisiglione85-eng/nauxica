# Nauxica quick brand reference

Brand name: Nauxica

Payoff: HOSPITALITY, CONNECTED.

Public tagline: Hospitality, connected.

One line positioning:
Premium hospitality management for Catania and Sicily, connecting owners, guests, operations and local partners.

Typography:
Display / logo: Bodoni FLF
Support / UI / payoff: Avenir

Palette:
Charcoal #0F1720
Stone #444A52
Sand #F2ECE4
Linen #F7F5F1
Terracotta #C5683D

Primary logo use:
Use the full logo in brand documents and presentations.
Use the wordmark or horizontal logo in the website navbar.
Use the white logo version on dark backgrounds.
Use the logo mark for favicon and app icons.
