# Nauxica brand folder

This folder contains the current Nauxica brand direction based on the updated logo system.

## Core files

1. nauxica_visual_board_v2.png  
Use as the main visual reference for brand mood, logo placement, palette, typography, glyph direction and dashboard style.

2. nauxica_visual_board_v2.pdf  
Presentation friendly version of the visual board.

3. nauxica_palette.json  
Structured palette and type data for developers and design tools.

4. nauxica_color_tokens.css  
CSS variables ready to copy into the website stylesheet.

5. nauxica_palette_reference.png  
Standalone palette image for quick sharing.

6. nauxica_typography.json  
Typography notes for brand and web use.

## Logo fonts

Logo wordmark: Bodoni FLF  
Payoff and support copy: Avenir

## Brand colours

Charcoal: #0F1720  
Stone: #444A52  
Sand: #F2ECE4  
Linen: #F7F5F1  
Terracotta: #C5683D

## Brand tone

Premium, minimal, Mediterranean, connected, calm, intelligent and hospitality led.

## Website use

Use Linen as the main background, Charcoal for text, Stone for supporting text, Terracotta for accents and CTAs, Sand for soft UI panels.

## Note about fonts

Do not store or share font files in this folder. Use licensed font sources or web safe fallbacks.
